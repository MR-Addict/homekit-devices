# 小米电视（television）

在家庭 App 中显示为 `Xiaomi TV`，支持电源、音量加减、方向、确认、返回与主页。

ESP32E-N4 红外板：发射 GPIO4，供电 GPIO21（高电平）。小米 L43M5-EK 的按键波形保存在 `ir_codes.h`。

按 [HomeSpan 共用指南](../README.md) 安装依赖、选择分区并烧录。BLE 配网名称为 `HS-IRTV-xxxx`，默认配对码 **466-37-726**。

配对后在控制中心的 Apple TV 遥控器中选择它。方向按钮在「设置 → 辅助功能 → Apple TV 遥控器」中开启；手机侧边键调音量，`i` 对应主页。

ESP32 独立供电，在路由器中为电视保留 `192.168.10.173`。电源状态通过 Ping 自动同步：关机约需 5–7 秒，开机需等待电视联网；网络故障可能被判为关机。
