# WOL / PVE OpenWrt 部署

[通用安装与维护](../README.md) · [应用使用与配置](../../../docs/wol.md)

## 配置准备

按通用流程选择 `app='wol'`，复制本目录 `config.example.yaml` 为 `config.yaml`。填写目标 MAC、子网广播地址和实际 LAN 接口；示例监听端口为 `32042`，配对目录为 `/etc/homekit-wol/db`。

普通设备不配置 `options`，仅发送唤醒包；PVE 目标添加 `type: pve`、固定 IPv4 `host` 与完整 `token`。Token 创建、权限和状态判断见应用文档。实际配置被 Git 忽略，含 Token 时保持 `0600` 权限。

按通用流程安装、启动并添加到 Apple Home。已有部署保留配对目录；从旧单设备配置升级时按应用文档处理。

## 验收

- 普通 WOL：目标 BIOS 和网卡已启用 WOL，在家庭 App 触发后目标唤醒，开关两秒后复位。
- PVE：日志确认唯一节点发现与状态读取，开关显示检测到的状态。
- 先确认来宾正常关机及自启动策略，再验证正常关机 → 检测离线 → WOL → API 恢复，并核对来宾恢复情况。
- 验证 PVE 网页手动关机后的状态同步、重复请求及网络中断与恢复。
- 重启服务后确认 Apple Home 配对保留，并由客户端验证控制与通知。

PVE 关机验收使用不依赖宿主机内虚拟路由器的管理与唤醒路径，预先确保可现场恢复。部署和命令发送成功不等于唤醒或客户端验收通过。
